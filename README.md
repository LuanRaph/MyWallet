MyWallet — Controle Financeiro Pessoal

Aplicação fullstack para controle financeiro pessoal com autenticação JWT, dashboard interativo e persistência de dados na nuvem.

## 🔗 Acesse o projeto
**[mywallet-x97u.onrender.com](https://mywallet-x97u.onrender.com/login.html)**

---

## ✨ Funcionalidades

- Cadastro e login com autenticação JWT
- Cada usuário vê apenas suas próprias transações
- Adicionar, editar e excluir transações (CRUD completo)
- Dashboard com gráfico de entradas x saídas (Chart.js)
- Dark mode
- Persistência com PostgreSQL na nuvem
- Loading spinner e confirmação antes de excluir

---

## 🛠️ Tecnologias

**Frontend**
- HTML, CSS, JavaScript
- Bootstrap 5 + Bootstrap Icons
- Chart.js

**Backend**
- Node.js + Express
- PostgreSQL (Neon)
- JWT (jsonwebtoken)
- bcrypt
- dotenv
